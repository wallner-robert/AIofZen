## 9 Feb 2026 - DeepSeek 3

Summary of Our Course Planning Session

We've collaboratively designed a practical, mobile-first AI course from the ground up. Here's what we've accomplished:

Core Philosophy Established:

· Brain-dead simple, practical approach - No theory, just "doing"
· Mobile-only premise - Everything works on a Samsung Galaxy phone
· Project-based learning - Always moving toward concrete outputs

Course Structure Finalized:

1. Setup - Creating a coherent digital identity (phone profile + Google account)
2. LLM Chatbots - Foundation section covering:
   · Basic access and iterative chatting
   · Vision and hearing capabilities (analyzing media)
   · Key innovation: Two-document system (log.md + README.md) for project memory
3. Image Generators - Practical image creation
4. Video - To be defined
5. Audio - Comprehensive coverage (TTS, cloning, voice-to-voice, sound effects)
6. Suno - Music generation

Key Pedagogical Insights Developed:

· Browser-first approach for LLMs (apps are optional "bonus")
· Text-only foundation to build correct mental models (avoiding TTS confusion)
· Iterative refinement as core methodology (not magic prompts)
· Git-commit analogy for project management with AI
· Universal minimum system for any project type

Unique Value Proposition:

· Teaches sustainable methodology, not just tool features
· Two-document system for continuity across sessions
· Mobile-native workflow - no desktop assumptions
· Progressive complexity from single chats to complex project management

The course is designed to transform beginners from passive consumers into active directors of AI tools, with a professional workflow they can apply to any project.
